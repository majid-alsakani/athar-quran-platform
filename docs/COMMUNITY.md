# مجتمع أثر

مرحباً بكم في المساحة المفتوحة لمنصة **أثر**. نسعى إلى بناء أدوات عربية عملية لإدارة حلقات تحفيظ القرآن، تجمع بين وضوح الإدارة، متابعة الأسرة، وتحفيز الطالب في تجربة واحدة محترمة وهادئة.

## كيف يمكن المساهمة؟

نرحّب بالمساهمة في تحسين واجهات RTL، بناء تقارير جديدة، توسيع اختبارات الصلاحيات، تحسين تجربة الجوال، مراجعة النصوص العربية، وتوثيق التكاملات. اقرأ ملف [المساهمة](../CONTRIBUTING.md) ثم افتح Issue أو Pull Request صغيراً ومحدد الهدف.

> نطلب من الجميع الحفاظ على لغة محترمة وشاملة؛ راجع [مدونة السلوك](../CODE_OF_CONDUCT.md) قبل المشاركة.

## المجتمع

تابع **[مجتمع إتقان](https://community.itqan.dev/)** للنقاشات والأدوات والأفكار المتعلقة بالتقنيات القرآنية.
