# Privacy and child safety

تتعامل المنصة مع بيانات تعليمية تخص طلاباً وقد يكون بعضهم قاصرين، لذلك يجب التعامل مع أقل قدر من البيانات اللازمة فقط. لا تستخدم أسماء الطلاب أو ملاحظات المعلمين في مواد تسويقية أو لقطات شاشة عامة أو نسخ تجريبية.

| الإجراء | الضابط المطبق |
| --- | --- |
| سجل الطالب | لا يراه الطالب إلا لنفسه، وولي الأمر عبر رابط موثق، والمعلم عبر حلقة مسندة إليه. |
| بيانات المؤسسة | تقيد الاستعلامات الإدارية والمعلمين بمعرف المؤسسة. |
| الواجهة التجريبية | تستخدم أوصافاً عامة فقط ولا تحفظ تعديلات أو تنشئ بيانات قاعدة بيانات. |
| التصدير | يقتصر CSV على مدير المؤسسة ومن سجلات المؤسسة نفسها. |
| الملاحظات | يكتب المعلم الملاحظة الضرورية للتعلم فقط، من دون معلومات حساسة غير لازمة. |

قبل تشغيل المنصة مع مركز فعلي، ينبغي تحديد سياسة الاحتفاظ بالبيانات، واعتماد من يملك صلاحية المدير، ومراجعة المستخدمين المضافين بشكل دوري.
