# Pilot metrics

يُقاس نجاح التجربة الأولى بالاستخدام الفعلي لا بعدد الشاشات. ابدأ بحلقة أو حلقتين فقط لمدة أربعة أسابيع، ثم راجع المؤشرات التالية مع المعلمين والمدير.

| المؤشر | طريقة القياس | هدف التجربة الأولي |
| --- | --- | --- |
| سرعة الحضور | وقت تسجيل حضور الجلسة | أقل من دقيقتين للحلقة الصغيرة |
| اكتمال المتابعة | نسبة الطلاب الذين لهم حضور أو متابعة بعد الجلسة | أكثر من 80% |
| استخدام المعلم | عدد المعلمين الذين سجلوا جلسة أسبوعياً | أكثر من 70% من المعلمين المضافين |
| قراءة الأهل | نسبة الإشعارات التي علّمت كمقروءة | ملاحظة اتجاه الاستخدام، لا اعتبارها مؤشراً وحيداً |
| سلامة الوصول | محاولات الوصول المرفوضة وأخطاء الصلاحيات | صفر أخطاء حرجة |

تسجل الملاحظات النوعية أيضاً: ما الذي أبطأ المعلم؟ هل فهم ولي الأمر التقرير؟ وهل احتاج المدير إلى حقول إضافية قبل تعميم التجربة؟
