# حزمة إطلاق «أثر» للمساهمين الأوائل

**الرابط الأساسي:** https://github.com/majid-alsakani/athar-quran-platform

## إعلان منتدى مجتمع إتقان

### العنوان

نفتح «أثر» للمجتمع: منصة عربية مفتوحة المصدر لإدارة حلقات تحفيظ القرآن

### النص

السلام عليكم مجتمع إتقان،

يسعدنا إطلاق **أثر** كمشروع مفتوح المصدر لبناء منصة عربية تساعد حلقات تحفيظ القرآن في إدارة الحلقات والجلسات، متابعة الحفظ والمراجعة والتجويد، الحضور، النقاط، المهام، التقارير، الإشعارات، والرسائل الداخلية.

صممنا «أثر» من البداية بالعربية واتجاه RTL، مع صلاحيات واضحة للمدير والمعلم وولي الأمر والطالب. هدفنا ليس بناء لوحة إدارة فقط، بل تطوير تجربة عملية ومحترمة تجعل المعلم والأسرة والطالب أقرب إلى رحلة حفظ أوضح وأكثر تحفيزاً.

فتحنا المستودع للمجتمع ونبحث عن المساهمين الأوائل في تطوير الواجهات العربية، تجربة الجوال، الاختبارات، التوثيق، مراجعة تجربة الحلقات، وتحسينات الوصول والصلاحيات.

إذا أردت المشاركة، يمكنك البدء بفتح Issue لفكرة أو مشكلة، اختيار مهمة مناسبة للمبتدئين، مراجعة التوثيق، أو تقديم Pull Request صغير وواضح. نرحب بالمساهمات التقنية والتصميمية والتربوية على السواء.

> المستودع: https://github.com/majid-alsakani/athar-quran-platform
