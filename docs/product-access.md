# أثر — نطاق المنتج وخريطة الصلاحيات

«أثر» منصة ويب عربية لإدارة حلقات تحفيظ القرآن الكريم. تجمع الإدارة والمعلمين وأولياء الأمور والطلاب في سجل موحّد للحلقات والجلسات والحضور والحفظ والمراجعة والنقاط والإشعارات، مع عزل بيانات كل دور عن الآخر.

| الدور | نطاق الوصول | الإجراءات المسموحة | المسارات الأساسية |
|---|---|---|---|
| المدير | جميع الحلقات والحسابات والتقارير | إدارة أدوار الحسابات، إنشاء الحلقات، تعيين المعلمين، تسجيل الطلاب، مراجعة المؤشرات | `/dashboard`، `/circles`، `/students`، `/reports` |
| المعلم | الحلقات المعيّنة له وطلابها فقط | إنشاء الجلسات، رصد الحضور، تسجيل الحفظ والمراجعة، منح النقاط، إنشاء المهام، التواصل ضمن العلاقات المصرح بها | `/dashboard`، `/attendance`، `/progress`، `/tasks` |
| ولي الأمر | الأبناء المرتبطون به فقط | متابعة الحفظ والحضور والنقاط والمهام والتقارير، التواصل مع معلمي الأبناء | `/dashboard`، `/students`، `/progress`، `/points`، `/messages` |
| الطالب | سجله الشخصي فقط | استعراض التقدم والمهام والجدول والنقاط والإشعارات، التواصل مع معلمه أو ولي أمره المرتبط | `/dashboard`، `/progress`، `/tasks`، `/schedule`، `/points` |

## سياسات العزل

تُطبّق الصلاحيات في طبقة الخادم قبل الوصول إلى البيانات. يستطيع المدير الوصول الشامل، بينما يُقيّد المعلم بملكية الحلقة، ويُقيّد ولي الأمر بعلاقة ولي الأمر والطالب، ويُقيّد الطالب بمعرفه الشخصي. كما تتحقق الرسائل الداخلية من العلاقة بين المرسل والمستلم؛ فلا يمكن التواصل خارج الحلقة أو الرابط العائلي المصرح به.

## الأحداث الآلية

عند رصد الحضور أو الغياب أو التأخر، يُنشأ إشعار داخلي لولي الأمر المرتبط. وعند تسجيل تقدم الحفظ مع نقاط، يُضاف سجل نقاط للطالب ويصل إشعار له ولولي الأمر. كذلك ينشئ إسناد مهمة أو إرسال رسالة إشعاراً داخلياً للمستلم.
