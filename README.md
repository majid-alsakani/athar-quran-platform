# أثر للحلقات | Athar Circles

أثر منصة عربية RTL لإدارة حلقات التحفيظ. تجمع لوحة عامة تعريفية مع مساحة استخدام محمية للأدوار الأربعة: المدير، المعلم، ولي الأمر، والطالب.

## ما الذي يعمل الآن؟

| المجال | ما يتضمنه |
| --- | --- |
| المؤسسة والأدوار | إنشاء مؤسسة، تعيين أدوار للمستخدمين المسجلين، وربط ولي الأمر بالطالب. |
| الحلقات والجلسات | إنشاء الحلقات، إلحاق الطلاب، إنشاء الجلسات، وتسجيل الحضور السريع. |
| المتابعة | حفظ نطاق الحفظ والمراجعة ودرجة التجويد وملاحظات المعلم. |
| التقارير | تقدم أسبوعي مقيد بالصلاحيات، تنزيل PDF في المتصفح، وPDF خادمي محفوظ للتقارير الأسبوعية، وتصدير CSV للمدير. |
| التحليلات | رسمان تفاعليان لثمانية أسابيع من الحضور والمتابعة والنقاط، من بيانات الطالب الفعلية فقط. |
| العرض | وضع فاتح/ليلي محفوظ محلياً، متاح من الصفحة العامة والوضع التجريبي ولوحات الاستخدام. |
| الإشعارات | تنبيهات داخل التطبيق للحضور والمتابعة والتقارير. |
| التجربة | صفحة عامة آمنة، مع أمر اختياري ينشئ مؤسسة تجربة معزولة وموسومة بوضوح لاختبار الرسم وPDF. |
| دعوات الأولياء | مسودات بريد أو واتساب، رموز قبول منتهية الصلاحية، موافقة صريحة، ومنع التكرار؛ لا يوجد إرسال خارجي قبل إعداد مزود. |

## التشغيل المحلي

شغّل الأوامر التالية من جذر المشروع. لا تضف ملف `.env` إلى المستودع؛ توفر بيئة النشر المتغيرات الحساسة والاتصال بقاعدة البيانات تلقائياً.

```bash
pnpm install
pnpm check
pnpm test
pnpm dev
```

## الإعداد الأولي للمؤسسة

بعد تسجيل المدير الدخول، ينشئ المؤسسة من لوحة التحكم. يسجل بقية المستخدمين دخولهم مرة واحدة، ثم يظهرون في صفحة **المستخدمون** ليعيّن المدير دورهم. بعد ذلك يربط ولي الأمر بالطالب ويلحق الطالب بحلقته قبل بدء تسجيل الجلسات.

> لا تُضاف بيانات التجربة إلى مؤسسة فعلية. عند الحاجة إلى اختبار البيانات الحية، شغّل `ATHAR_SEED_DEMO=confirm pnpm tsx scripts/seed-demo.mjs` لإنشاء أو تحديث مؤسسة مستقلة موسومة بأنها تجريبية، تضم مدير المشروع ومعلمًا وولي أمر وطالبًا وحلقة وخمس جلسات وسجلات الحضور والتقدم. لا تستخدم الأداة أي بريد أو رقم اتصال حقيقي ولا ترسل رسائل خارجية.

## التقرير الأسبوعي التلقائي

تعمل تقارير الحضور والتقدم اليدوية من داخل المنصة فوراً. ينشئ التقرير الأسبوعي PDF عربيًا من الخادم ويحفظ **مفتاح الملف فقط** في قاعدة البيانات، ثم يسجل إشعارًا داخل التطبيق. أما الجدولة الأسبوعية التلقائية فتحتاج أن تكون النسخة العامة منشورة أولاً، لأن مشغّل الجدولة يستدعي المسار المحمي `/api/scheduled/weekly-report` في النشر العام.

لا يمكن للمدير تفعيل جدول إرسال خارجي إلا لولي أمر قبل الدعوة من حسابه وسجّل موافقته صراحة. يوجد حاليًا سجل تسليم idempotent يحتفظ بالحالة `queued` عند غياب مزود بريد أو واتساب؛ لا يُسجل `deliveredAt` ولا تُرسل أي رسالة حتى يختار مالك المشروع مزودًا ويضبط اعتماده. بعد النشر وإعداد القناة، يفتح المدير صفحة **التقارير** ويحدد ولي الأمر والطالب ثم يفعّل الجدول المطلوب بتوقيت UTC.

## التحقق قبل النشر

يجب تشغيل `pnpm check` و`pnpm test` بعد كل تعديل مؤثر. يتضمن المشروع اختبارات لوحدات الصلاحيات وحدود الوصول ومنطق بداية الأسبوع وبناء ملخص التقرير وتطبيع مستلمي الدعوات وشرط الموافقة ومحول التسليم الخارجي الآمن.

## مشاركة تقرير PDF

يفتح المستخدم صفحة **التقدم** ويختار الطالب الذي تسمح له صلاحياته بعرضه. يظهر زر **تنزيل التقرير PDF** بجانب سجل المتابعة؛ ينشئ الملف من التقرير الظاهر فقط، بما يشمل الحضور والسجلات وملاحظات المعلم. لا توجد واجهة عامة أو رابط مباشر يلتف على صلاحيات التقرير.

راجع الملفات التالية للتفاصيل: `docs/roles-and-permissions.md`، و`docs/report-automation.md`، و`docs/privacy-and-child-safety.md`، و`docs/pilot-metrics.md`.
